# Multi-Site Enterprise Network Topology & Automated Infrastructure

This repository contains the complete EVE-NG lab topology and comprehensive documentation for a multi-site enterprise network infrastructure featuring VLAN segmentation, WAN connectivity, cross-site tunneling, server integration, and automated workflows.

---

## 📁 Repository Contents

* **`Multi-Site Enterprise Network Topology & Auto....zip`**
  Contains the core EVE-NG lab file (`.unl`). Unzip this file to import the full network topology, node positioning, interconnections, and configurations directly into your EVE-NG environment.

* **`Enterprise_Network_Project_Report.pdf`**
  The detailed project documentation covering network design architecture, IP addressing schemes, routing protocols, server roles (Active Directory, Web/File sharing, DHCP, DNS), security configurations, and automation scripts.

---

## 🚀 How to Use the Lab File

1. Download and extract the `.zip` file to get the `.unl` topology file.
2. Log into your **EVE-NG** web console.
3. Click **Import** on the main menu and select the extracted `.unl` file.
4. Ensure your EVE-NG instance has the required node images mapped (Cisco IOS/Nexus, Windows Server, Linux, FortiGate) to match the interface mapping.
5. Start the nodes and explore the running configurations.
